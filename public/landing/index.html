Core Capabilities

The Four Pillars of ASKbro

Designed from the ground up to empower users with speed, intelligence, and rigorous security boundaries.

1. The Eyes: Read the Web

Extracts noise-free article text via Mozilla Readability and produces structured 3-part intelligence briefs.

  • TL;DR + 5 Key Takeaways + Next Steps
  • YouTube summary with clickable video-seeking timestamps
  • English & conversational Hinglish toggle

2. The Brain: Understand Page

Chats with live DOM text strictly bounded inside sanitized XML containers to eliminate hallucinations.

  • Context menus: Explain, Translate, Draft reply
  • "Screenshot-and-Ask" vision for tables & charts
  • Automatic Groq Cloud fallback on HTTP 429 rate limits

3. The Hands: Controlled Action

Scans actionable elements into closed Shadow DOM badges and prompts step-by-step actions with human approval.

  • "Find it for me" element spotlighting & smooth scroll
  • Strict Zod schemas (click, type, select, scroll, done)
  • Dry Run simulation & MV3 worker hibernation persistence

4. Memory & Safety Guardrails

Local user profile memory and reusable custom skills coupled with deterministic code-level safety filters.

  • Local-only profile storage (zero external telemetry)
  • Reusable skills engine with JSON export & import
  • Hardcoded banking blacklist & regex OTP/CVV filters
Security by Code, Not by Prompt

Deterministic Safety Guardrails

ASKbro does not rely on LLM alignment to stay safe. Hardcoded client-side filters intercept and reject risky operations unconditionally.

Vector Protection Rule Enforcement Mechanism Status
Banking & Payments Domains matching bank, paytm, phonepe, razorpay, upi, stripe, checkout Domain Guard disables agent loop immediately and overlays protective shield. 🚫 Blocked Hard
Passwords & PINs input[type="password"] or regex /(pin|pass|secret)/i Scanner completely excludes field from scans and badges; executor rejects interaction. 🚫 Excluded & Blocked
OTP & 2FA Codes autocomplete="one-time-code" or regex /(otp|cvv|mfa)/i Two-tier defense-in-depth: hidden from LLM payload, rejected by content executor. 🚫 Excluded & Blocked
Credit Cards & CVV autocomplete*="cc-" or regex /(card|cvv|expir)/i Zero DOM visibility; client filters prevent AI from proposing or typing digits. 🚫 Excluded & Blocked
Consequential Actions Buttons with text like "Submit", "Place Order", "Pay Now", "Delete Account" Consequential Guard halts execution and requires secondary confirmation toggle. ⚠️ Secondary Approval
Infinite Loop Breaker Maximum steps threshold (default: 10 steps per user goal) Agent halts automatically when step counter exceeds budget to prevent loops. 🛡️ Active Bounding

Get Started

Install ASKbro in 60 Seconds

Zero complex compilers required for end users. Download the clean distribution ZIP and load it directly into Google Chrome.

01

Download Archive

Download the pre-packaged ASKbro-v1.0.0.zip release and unzip it into a folder on your computer.

02

Open Extensions

In Google Chrome, navigate to chrome://extensions and toggle on Developer mode in the top right.

03

Load Unpacked

Click the Load unpacked button and select the unzipped directory containing manifest.json.

04

Add API Key

Click the ASKbro icon to open the side panel, go to ⚙️ Settings, enter your free Gemini API key, and start browsing!

Frequently Asked Questions

Everything You Need to Know

Do I need a paid Gemini API key? +
No! ASKbro is engineered to run seamlessly on Google's generous free tier of Gemini 1.5 Flash-Lite. You also have the option to configure a free Groq Cloud API key as a zero-cost backup for HTTP 429 rate limit fallback.
Can ASKbro access my bank or make payments? +
Absolutely not. The hardcoded Domain Guard uses deterministic regex to immediately block execution on banking, UPI, and checkout domains (e.g. HDFC, Chase, Paytm, PhonePe, Razorpay, Stripe). The agent loop is completely disabled on these domains.
Can the agent read my passwords or OTP codes? +
No. The Field Guard actively filters out password inputs, one-time-code fields, and credit card patterns before they can ever be scanned, badged, or sent to the AI model. Additionally, the content script executor refuses to type into sensitive fields even if prompted.
Will ASKbro click things on its own? +
Never. ASKbro operates under a strict Human-In-The-Loop (HITL) approval architecture. Every proposed click, typing step, or dropdown selection must be reviewed and explicitly approved by clicking the "Approve" button. You can also test actions harmlessly with "Dry Run".
Is my personal data sent to any third-party servers? +
No. Your user profile, custom skills, and execution history stay 100% inside your local Chrome browser storage (chrome.storage.local and chrome.storage.session). Only the necessary page prompt text is communicated directly to the Gemini API endpoint.
